# Excel Financial Auditor

Локальное приложение для анализа финансовых Excel-книг (`.xlsx`, `.xlsm`). Оно не изменяет исходный файл: для скачивания создаётся отдельная копия с подсветкой проблем и листом `_Audit_Report`.

## Возможности

- профилирование листов, периодов, формул, скрытых листов и типов финансовых отчётов;
- статическая проверка `#REF!`, `#DIV/0!`, `#VALUE!`, `#NAME?`, `#N/A`, `#NUM!`, `#NULL!`;
- сравнение соседних формул с учётом относительных/абсолютных ссылок;
- поиск hardcode внутри вычисляемого ряда, ошибок копирования и несовпадающих `SUM`;
- проверка внешних ссылок и циклических зависимостей с цепочкой;
- сверки Balance Sheet, Gross Profit, EBITDA, EBIT и Net Income, если соответствующие строки обнаружены;
- уровни severity/confidence, риск-скор и объяснения; фильтры по severity и листу;
- экспорт подсвеченной копии и `_Audit_Report`; лог в `logs/audit.log` без содержимого исходных файлов.

## Установка и запуск

Требуется Python 3.12+.

```bash
pip install -r requirements.txt
python run.py
```

Откройте адрес, напечатанный в терминале (по умолчанию `http://127.0.0.1:8765`), выберите Excel-файл и нажмите **Analyze workbook**. Для остановки сервера нажмите `Ctrl+C`.

`LibreOffice` не обязателен в MVP. Анализ формул выполняется статически; вычисленные Excel-кэши читаются, если они присутствуют. Это важно: `openpyxl` не является Excel calculation engine.

## Настройка

`config.yaml` содержит порог балансовой сверки, аномалий и веса риска. Риск: `CRITICAL×10 + HIGH×5 + MEDIUM×2 + LOW×1`; 0–10 LOW, 11–30 MEDIUM, 31–70 HIGH, 70+ CRITICAL.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты генерируют контролируемые книги в `tests/data/`: корректную модель, broken reference, mismatch формулы, hardcode, Balance Sheet mismatch и circular reference.

## Известные ограничения MVP

- Формулы не пересчитываются внутри Python; для гарантированно актуальных численных результатов откройте/пересчитайте книгу в Excel или LibreOffice перед аудитом.
- Сложные Excel-функции (например, `XLOOKUP`, `SUMIFS`) пока анализируются по структуре только частично.
- Идентификация финансовых строк основана на названиях на английском; новые синонимы легко добавить в `app/analyzer/workbook_analyzer.py`.
- LLM-интерфейс намеренно не включён: движок детерминированный и локальный.
